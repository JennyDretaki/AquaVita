# AquaVita — HR Back Office

Εφαρμογή διαχείρισης προσωπικού και προγραμματισμού βαρδιών για τα υποκαταστήματα AquaVita (Grand, Esperides, Cooks, Ammos, Kahlua, Glaros, Petousis, Noble, Ida Village).

## Γιατί δημιουργήθηκε

Η σελίδα φτιάχτηκε ως **mobile-first back office για το HR**, ώστε να μπορεί γρήγορα να:

- επιλέγει μαγαζί και να οργανώνει το **ημερήσιο** ή **εβδομαδιαίο** πρόγραμμα
- τοποθετεί προσωπικό με **drag & drop**
- διαχειρίζεται πωλητές και θεραπευτές (προσθήκη, διαγραφή, επαναφορά εντός 7 ημερών)
- εξάγει το πρόγραμμα σε **Excel**

Στόχος είναι ένα απλό εργαλείο χωρίς περίπλοκες οθόνες, κατάλληλο για χρήση από κινητό ή tablet στην καθημερινή λειτουργία των καταστημάτων.

## Τεχνολογίες

| Τεχνολογία | Ρόλος |
| --- | --- |
| **React 19** | UI και λογική της εφαρμογής |
| **TypeScript** | Τύποι και ασφάλεια κώδικα |
| **Vite** | Build tool και dev server |
| **@dnd-kit** | Drag and drop προσωπικού στις βάρδιες |
| **date-fns** | Ημερομηνίες (ημέρα / εβδομάδα) |
| **xlsx (SheetJS)** | Εξαγωγή προγράμματος σε Excel |
| **lucide-react** | Εικονίδια |
| **localStorage** | Τοπική αποθήκευση δεδομένων στον browser |

## Προαπαιτούμενα

Πριν ξεκινήσεις, χρειάζεσαι:

1. **Node.js** (προτείνεται LTS, π.χ. 20 ή νεότερο) — [nodejs.org](https://nodejs.org/)
2. **npm** (έρχεται μαζί με το Node.js)
3. **Git** (προαιρετικά, για clone από GitHub)

Έλεγχος εγκατάστασης στο terminal:

```bash
node -v
npm -v
```

## Tutorial: κατέβασμα βιβλιοθηκών και εκκίνηση

### 1. Κατέβασμα του project

Από GitHub:

```bash
git clone https://github.com/JennyDretaki/AquaVita.git
cd AquaVita
```

Αν έχεις ήδη τον φάκελο τοπικά, απλά άνοιξέ τον στο terminal:

```bash
cd path/to/AquaVita
```

### 2. Εγκατάσταση βιβλιοθηκών

Οι εξαρτήσεις περιγράφονται στο `package.json`. Για να τις κατεβάσεις όλες μαζί:

```bash
npm install
```

Αυτό δημιουργεί τον φάκελο `node_modules` με React, Vite, dnd-kit, xlsx κ.λπ.

Αν χρειαστεί να προσθέσεις νέα βιβλιοθήκη αργότερα:

```bash
npm install όνομα-πακέτου
```

Για dev-only εργαλεία:

```bash
npm install -D όνομα-πακέτου
```

### 3. Εκκίνηση σε development

```bash
npm run dev
```

Άνοιξε στο browser τη διεύθυνση που εμφανίζει το Vite (συνήθως `http://localhost:5173/`).

### 4. Build για παραγωγή

```bash
npm run build
```

Τα στατικά αρχεία δημιουργούνται στον φάκελο `dist/`. Προεπισκόπηση:

```bash
npm run preview
```

## Βασικές λειτουργίες

- **Αριστερή στήλη:** επιλογή υποκαταστήματος
- **Ημερήσιο / Εβδομαδιαίο:** εναλλαγή προβολής προγράμματος
- **Προσωπικό:** drag & drop στη βάρδια · ταξινόμηση ανά θέση ή αλφαβητικά
- **Ημερήσιο:** όποιος μπει σε μαγαζί δεν εμφανίζεται στα άλλα την ίδια μέρα
- **Διαγεγραμμένοι υπάλληλοι:** επαναφορά εντός 7 ημερών
- **Excel:** εξαγωγή του τρέχοντος προγράμματος
